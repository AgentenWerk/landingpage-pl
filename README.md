# Kosztorysant AI

Polska wersja landing page produktu wspierającego kosztorysantów w analizie
przedmiarów, wyszukiwaniu cen, przygotowaniu stawek i kontroli ryzyk.

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

Strona będzie dostępna pod adresem `http://localhost:3000`.

## Weryfikacja

```bash
npm run build
npm run lint
npm test
```

Formularz działa lokalnie w trybie demonstracyjnym i nie wysyła danych do
zewnętrznej usługi. Karta podglądu linku znajduje się w `public/og.png`.
